# AloneCraft Website

AloneCraft の製品紹介とドキュメントのサイト。Astro + Starlight の静的サイト。仕様は [SPEC.md](SPEC.md) を参照。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm install` | 依存パッケージを入れる |
| `npm run dev` | 開発サーバー（`http://localhost:4321`） |
| `npm run build` | `dist/` へ静的サイトを出力する |
| `npm run preview` | ビルドした `dist/` を確認する |
| `npm run gen:api` | Omni のソースから `src/data/api/omni.json` を作る（.NET 10 SDK が必要。Omni の場所は環境変数 `OMNI_ROOT`、既定は `D:/Unity/6.6/Omni`） |
| `npm run gen:reference` | `omni.json`、許可リスト、説明文からリファレンスのページを作る |
| `npm run check:links` | ビルドした `dist/` の内部リンクの切れを検査する |
| `npm run check:reference` | 説明の無いメンバーも失敗にして生成し、生成物に差分が無いことを確かめる（公開の前に通す） |

## 置き場

| パス | 内容 |
| --- | --- |
| `src/pages/` | ブランドページ（トップ、製品紹介）。Starlight を使わない独自のページ |
| `src/i18n/ui.ts` | ブランドページの日英の文言 |
| `src/content/docs/<lang>/` | ドキュメント（Starlight）。`ja` が正本、`en` はその翻訳 |
| `src/assets/` | 画像（ビルド時に最適化される） |
| `tools/ApiExtract/` | Omni の C# と HLSL を構文で解析して API の一覧を書き出すツール |
| `src/data/api/omni.json` | 上のツールの出力（生成物） |
| `reference/omni/allowlist.yaml` | リファレンスに載せる型 |
| `reference/omni/notes/<lang>/` | リファレンスの手書きの説明（型ごと） |
| `src/content/docs/<lang>/omni/reference/` | リファレンスのページ。先頭に `generated by scripts/gen-reference.mjs` とあるものは生成物なので、直接直さない |
| `src/styles/site.css` | ブランドページのスタイル |
| `src/styles/starlight.css` | ドキュメントの色 |

日本語のページを変えたら、同じ作業で英語のページも直す。

## リファレンスの更新

1. `npm run gen:api` で Omni の今のソースを読む。
2. `npm run gen:reference` でページを作る。型が消えた、名前が変わった、説明文が存在しないメンバーを指している、などのときは失敗するので、許可リストと説明文を直す。
3. 新しい型を載せるときは、`allowlist.yaml` に足してから `node scripts/gen-reference.mjs --scaffold` を実行すると、説明文の雛形（日本語にはソースの XML コメントを下書きとして入れる）ができる。
4. 説明の無いメンバーは `node scripts/gen-reference.mjs --dry-run --verbose` で一覧できる。
