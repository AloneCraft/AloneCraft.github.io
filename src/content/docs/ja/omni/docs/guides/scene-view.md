Omni は Scene View に「Omni」という Overlay を加えます。この Overlay で、View ごとに標準表示と Radial 表示を切り替え、視点の位置と角度を Logical 座標で扱います。Scene View の Unity のカメラは表示用の写しで、視点の正本は Logical の位置と姿勢です。

## Overlay の項目

透視投影の Scene View では、Overlay に次の項目が出ます。

| 項目 | 内容 |
| --- | --- |
| RMB回転基準 | 右ドラッグで見回すときの基準。「ワールド」と「視点」から選ぶ |
| RadialCamera | 圧縮の設定を借りる、Scene の中の `RadialCamera` を選ぶ。「標準カメラ」を選ぶと、その View は通常の表示になる |
| 視点 | 「主観」と「客観」から選ぶ。RadialCamera を選んでいるときだけ出る |
| 設定元のInspectorを開く | 設定元の `RadialCamera` を、対象を固定した Property Editor で開閉する。Hierarchy の選択は変わらない |
| 設定元カメラへ視点を合わせる | 押した瞬間だけ、Scene View の位置・向き・垂直の画角を設定元のカメラに合わせる |
| 変形前、変形後、対応点を結ぶ | 比較表示の設定。「客観」のときだけ出る |
| Omni Manager | チェックで Omni Manager のウィンドウを開閉する。ウィンドウの表示と連動する |
| 位置、角度 | 視点の Logical の位置と角度。値を入れて Enter を押すと、その位置・向きへ動く |
| 操作・表示設定 | 描画経路、視点編集、安全境界、グリッド、ナビゲーションの設定 |
| デバッグ | 診断用の表示 |

RMB回転基準の「ワールド」は、World の Y 軸を水平の見回しの基準にします。真上や真下の近くでは、右ボタンを押したときのカメラの上方向へ滑らかに切り替えて、画面が回らないようにします。「視点」は、右ボタンを押したときのカメラの上方向を常に使います。

座標の欄には、Unity の Transform の値ではなく、Logical の位置と角度が出ます。角度の欄は World の Euler 角（度）で、yaw・pitch・roll の操作ではありません。

:::note
複数の Scene View は、RadialCamera や視点の選択を互いに共有しません。
:::

### Overlay を隠したとき

Overlay を非表示にすると、その View は標準の表示に戻り、進行中の操作は終わります。Logical の位置、視線の向き、ピッチ、ヨー、zoom は保ちます。画面のロールだけを Unity の標準の上方向へ戻します。再び表示すると、RadialCamera の選択と RMB回転基準を保ったまま操作を続けられます。

## 主観と客観

| 視点 | 見えるもの |
| --- | --- |
| 主観（既定） | 選んだ `RadialCamera` の設定を Scene View に適用し、Scene View 自身を中心に Radial で描く |
| 客観 | 選んだ `RadialCamera` の位置を圧縮の中心にし、その圧縮した空間を Scene View の視点から見る（比較表示） |

主観では、写像が視線の向きを保ちます。そのため、標準の描画で表せる範囲の画像は、標準の描画と同じになります。それより遠いものは、Radial の表示でだけ見えます。

「設定元カメラへ視点を合わせる」は、合わせ続ける同期ではありません。合わせた後は、通常どおり手で操作できます。

- 設定元が平行投影のときは、位置と向きだけを合わせ、画角は合わせません。
- 設定元が分割画面の一部を使うカメラのときは、縦の範囲は合いますが、横の範囲は Scene View のウィンドウと縦横比が違うので一致しません。

### 比較表示

客観では、写像の前と後の姿を同じ Scene View の視点から比べます。

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 変形前 | 写像する前の位置の表示方式。None（表示しない）、Wireframe、Shading | None |
| 変形後 | 写像した後の位置の表示方式。None、Wireframe、Shading | Shading |
| 対応点を結ぶ | 変形前と変形後の対応する頂点を線で結ぶ | オフ |

- 比較表示は Scene View の表示の状態です。Game View、Player、Scene の保存データ、Selection を変えません。Renderer の有効・無効、GameObject の active、Hierarchy の目のアイコンも変えません。
- 変形前・変形後がどちらも None で、対応点を結ぶがオフのときは、比較の対象は 0 件です。背景、グリッド、カメラやライトのギズモは残ります。
- 変形前の Shading は、近いものから 256 個までを描きます。描かなかった数は Overlay に「負荷上限のため {0} 件を描画していません（近いものから順に描いています）。」と出ます。選択の判定には影響しません。

比較表示を描けないときは、Overlay に理由が出ます。

| 表示 | 対処 |
| --- | --- |
| ⚠ 有効な RadialCamera を持つ基準カメラが見つからないため、比較表示は描画されません。 | 有効な `RadialCamera` を持つカメラを用意し、RadialCamera の欄で選ぶ |
| ⚠ このシーンに Radial マテリアルの対象がありません。（以下略） | Omni Manager で対数描画に切り替える（[標準描画と対数描画を切り替える](../../getting-started/switch-rendering/)） |
| 比較対象が画面内にありません（すべて視錐台の外です）。 | 視点を対象へ向ける |

## 視点の操作

Omni の視点の操作は、Logical 座標の上で行います。原点から遠い場所でも、`float` の丸めで移動が消えることはありません。

| 操作 | 動き |
| --- | --- |
| F、Hierarchy のダブルクリック | 選択した対象をフレーミングする。同じ対象で繰り返すと、遠い枠と近い枠を交互に使う |
| ホイール | 選択した対象へ近づく・離れる。動く量は表面までの残りの距離に比例する |
| 中ボタンのドラッグ | 押した点の表面を、カーソルに 1:1 で追従させてパンする。物体は動かない |
| Alt + 左ドラッグ | 今の注視点を中心に回る（Orbit） |
| 右ドラッグ | 見回す。目の位置は動かない |
| 右ドラッグ + W/A/S/D/Q/E | 飛ぶ。右ボタンを押したままホイールを回すと、速さの倍率が変わる |
| ポインターを重ねる | ポインターの先の一番手前の Renderer を、シアンの輪郭で示す。選択は変わらない |

- F は Edit > Shortcuts の `Omni/Frame Logical Selection` です。標準の表示、客観、主観のどれでも働きます。
- 親を選んで F を押すと、子の Renderer をすべて包む範囲の中心と大きさでフレーミングします。子を 1 つだけ選んだときは、その子だけをフレーミングします。
- 中ボタンのドラッグで背景を掴んだときは、今の Pivot を中心に通常のパンをします。
- 飛ぶ速さは、選択した対象の表面までの距離から決まります。何も選択していないときは、見えている物までの距離から求めた速さの 4 倍です。
- Overlay には、Pivot または選択した対象の表面までの距離と、飛ぶ速さが「Nav: pivotまで {0} ｜ 飛行速度 {1}」の形で出ます。
- 見回しと Orbit は、2D モードと回転のロックの挙動を変えません。

Scene を切り替えた後、新しい Scene の物が画面に 1 つも無く、視点が十分に離れているときだけ、一度だけ自動でフレーミングします。すでに何か見えているとき、操作の途中のときは、視点を変えません。

### 視点編集の補助

「操作・表示設定」の「視点編集」には、注視点と距離を保ったまま 15° ずつ回すボタン（左・右・上・下）、一定の倍率で近づく・離れるボタン、フォーカスする前の視点へ戻るボタンがあります。これらは「主観」の Radial 表示のときだけ使えます。

同じ操作は、Edit > Shortcuts の `Omni/Editing` にもあります。初期のキーは割り当てていません。Unity の既存のキーと重ならない組み合わせを設定してください。

### ナビゲーションの設定

「操作・表示設定」の「独自ナビゲーション」で、次を調整できます。

| 項目 | 内容 |
| --- | --- |
| 自動速度の秒数 | 選択した対象の表面（または Pivot）までの距離を、およそこの秒数で進む速さを基準にする |
| 予備速度 | 基準の速さを自動で決められないとき（対象の内側にいるときなど）だけ使う |
| 飛行速度の段比率 | 右ボタン + ホイールの 1 段あたりの倍率。段の数に上限は無い |
| 接近の縮小率 | ホイール 1 段で、残りの距離が何倍になるか。既定は 95% が残る |
| 接近の最小距離 | ホイールで近づくときの、表面までの距離の下限 |
| ホイール感度 | ホイールの量がこの値を超えるごとに 1 段進む |
| 1回で進む段数の上限 | 速くホイールを回したときに、1 回で進む段数を抑える |
| 見回しを左右反転、見回しを上下反転 | 右ドラッグの見回しの向きを反転する |

## 選択

- クリックの結果は、当たり（Hit）、外れ（Miss）、判定できない（Unavailable）の 3 つです。修飾キーなしの本当の外れだけが選択を解除します。判定できないとき、UI の上のクリック、修飾キー付きの外れでは、選択を解除しません。
- ホバーとクリックの判定は GPU で行います。Collider は要りません。
- 同じ位置・同じ深度で重なる Renderer（LOD0、LOD1、LOD2 など）では、ホバーとクリックが別の Renderer を指すことがあります。
- Entities Graphics の Entity の選択輪郭は、Scene View の上部の `Gizmos` メニューの `Selection Outline` で表示します。オフにすると表示しません。

## 平行投影と対数グリッド

平行投影の Scene View では、RadialCamera の欄の代わりに次の項目が出ます。

| 項目 | 内容 |
| --- | --- |
| 対数グリッド | 画面の中央 50% を歪みの無い矩形にし、外側を対数で圧縮したグリッドを出す。オンの間は、Scene の物体も同じ投影で写す |
| データ型 | 画面の端が対応する値。`float` は `float.MaxValue`、`Logic` は Logical の値の最大値 |

## そのほかの表示の設定

「操作・表示設定」には、ほかに次の設定があります。

| 項目 | 内容 |
| --- | --- |
| 描画経路、実座標圏（物体） | `Auto` は、全体の AABB が実座標圏（物体）の中にある対象だけ元の Renderer で描く。`ForceProxy` は、その中でも有限な描画用の Proxy を使う |
| 安全境界 | Scene View の有限な安全境界。境界線は常に出る。「安全境界面を表示」で半透明の面も出す。通常の編集ではオフのままにする |
| グリッド | 「グリッドをカメラ追従」、「グリッド基準 (10^n m)」、面ごとの表示と色、「グリッドを既定へ戻す」 |
