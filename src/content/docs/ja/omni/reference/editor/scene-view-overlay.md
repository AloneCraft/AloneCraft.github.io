Scene View の Overlay「Omni」に出る項目を、上から順に一覧にします。操作の流れは [Scene View の操作](../../../docs/guides/scene-view/) を読んでください。

## Overlay の表示

- Overlay の名前は「Omni」です。Scene View の Overlay メニューで表示・非表示を切り替えます。既定で表示します。
- 項目の状態は Scene View ごとに持ちます。複数の Scene View は、RadialCamera や視点の選択を共有しません。
- Overlay を非表示にすると、その View は標準の表示に戻ります。詳しくはガイドの [Overlay を隠したとき](../../../docs/guides/scene-view/#overlay-を隠したとき) を読んでください。
- 「操作・表示設定」と「デバッグ」を開いて項目が増えると、Overlay の中がスクロールします。

## RMB回転基準

右ドラッグで見回すときの基準を選ぶドロップダウンです。

| 選択肢 | 動き |
| --- | --- |
| ワールド（既定） | World の Y 軸を水平の見回しの基準にする。真上や真下の近くでは、右ボタンを押したときのカメラの上方向へ滑らかに切り替えて、画面のロールを防ぐ |
| 視点 | 右ボタンを押したときのカメラの上方向を常に使う |

- 「ワールド」へ切り替えると、目の位置を保ったまま、視線を World の水平の姿勢へ戻します。
- 2D モードのとき、回転をロックしているときは操作できません。
- 選んだ値はプロジェクトの設定（`ProjectSettings/OmniEditorSettings.asset`）に保存します。

## 透視投影のときの項目

### RadialCamera

圧縮の設定（モード、半径、しきい値、Logical の near / far、表示の縮尺）を借りる `RadialCamera` を選びます。ボタンには選んだカメラの名前が出ます。押すと選択肢のメニューが開きます。

| 選択肢 | 内容 |
| --- | --- |
| 標準カメラ | この View を標準の Scene View の描画にする |
| `カメラ名 — Scene 名 › 親 › …` | そのカメラの `RadialCamera` の設定で、この View を Radial で描く |

- 選択肢に出るのは、読み込んでいる Scene の Camera のうち、有効な `RadialCamera` を持つものです。Prefab のアセット、プレビュー用の Scene、保存しないオブジェクトのカメラは出ません。
- 並びは、Hierarchy のルートに近いもの、先に読み込んだ Scene、Hierarchy の上にあるものの順です。
- 新しい Scene View では、並びの先頭のカメラを一度だけ自動で選びます。候補が無い間は、候補ができたときに選びます。一度選んだ後（「標準カメラ」を選んだ場合を含む）は、自動では選び直しません。
- 選んだカメラが無くなった、または `RadialCamera` が無効になったときは「標準カメラ」に戻ります。別のカメラへ自動で切り替えることはしません。
- 選んだカメラは Game View を描いていなくてもかまいません。
- 選択は Scene View ごとに、Editor を閉じるまで保持します。

「標準カメラ」以外を選んでいるときだけ、次の項目が RadialCamera の下に出ます。「標準カメラ」のときは、まとめて隠します。

### 視点

| 選択肢 | 内容 |
| --- | --- |
| 客観 | 選んだ `RadialCamera` の位置を圧縮の中心にし、その圧縮した空間をこの Scene View から見る（比較表示） |
| 主観（既定） | 選んだ `RadialCamera` の設定をこの Scene View に適用し、Scene View 自身を中心に Logical の空間を見る |

選択は Scene View ごとに、Editor を閉じるまで保持します。違いはガイドの [主観と客観](../../../docs/guides/scene-view/#主観と客観) を読んでください。

### 設定元のInspectorを開く

チェックで、設定元の `RadialCamera` を、対象を固定した Property Editor のウィンドウで開きます。チェックを外すと閉じます。Hierarchy の選択は変わりません。ウィンドウを手で閉じると、チェックも外れます。

### 設定元カメラへ視点を合わせる

押した瞬間だけ、Scene View の位置・向き・垂直の画角を設定元のカメラに合わせるボタンです。合わせ続けることはしません。

- 設定元のカメラが平行投影のときは、位置と向きだけを合わせます。画角は合わせません。
- 設定元のカメラが分割画面の一部を使うときは、縦の範囲は合いますが、横の範囲は一致しません。

### 変形前、変形後、対応点を結ぶ

比較表示の設定です。視点が「客観」のときだけ出ます。

| 項目 | 選択肢 | 既定 |
| --- | --- | --- |
| 変形前 | 写像する前の位置の表示。None（表示しない）、Wireframe、Shading | None |
| 変形後 | 写像した後の姿の表示。None、Wireframe、Shading | Shading |
| 対応点を結ぶ | オンで、変形前と変形後の対応する頂点を線で結ぶ | オフ |

比較表示を描けないとき、描き切れないときは、項目の下に次の行が出ます。どれかの項目が None やオフ以外のときだけ出ます。

| 表示 | 意味 |
| --- | --- |
| ⚠ 有効な RadialCamera を持つ基準カメラが見つからないため、比較表示は描画されません。 | 設定元のカメラが無い |
| ⚠ このシーンに Radial マテリアルの対象がありません。Omni Manager で放射マテリアルを適用してください。 | 比較の対象が無い |
| 比較対象が画面内にありません（すべて視錐台の外です）。 | 対象がすべて画面の外にある |
| 負荷上限のため {0} 件を描画していません（近いものから順に描いています）。 | 上限を超えた分を描いていない |

## 平行投影のときの項目

平行投影の Scene View では、RadialCamera とその下の項目の代わりに、次の項目が出ます。透視投影の設定とは別の機能で、値を共有しません。

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 対数グリッド | 画面の中央 50% を歪みの無い矩形にし、外側を対数で圧縮したグリッドを出す。オンの間は、Scene の物体も同じ投影で写す | オフ |
| データ型 | 画面の端が対応する値。`Float` は `float.MaxValue`、`Logic` は Logical の値の最大値 | `Float` |

圧縮の度合いは、カメラの `orthographicSize` と縦横比から自動で決まります。調整の項目はありません。

## Omni Manager

チェックで Omni Manager のウィンドウを開き、チェックを外すと開いているウィンドウを閉じます。ウィンドウを別の方法で開閉しても、チェックは表示に合わせて変わります。Editor の起動の途中など、Omni Manager を開く準備ができていない間は操作できません。ウィンドウの中身は [Omni Manager](../omni-manager/) を読んでください。

## Logical の位置と角度

Scene View の視点の Logical の位置と角度を出す欄です。Unity の Transform の値ではありません。

| 項目 | 内容 |
| --- | --- |
| 位置 X / Y / Z | 視点の Logical の位置（m）。値を入れて Enter を押すと、その位置へ動く。十進数と科学表記（`1.5e12` など）を入れられる |
| 角度 X / Y / Z | 視点の向き。World の Euler 角（度）。値を入れて Enter を押すと、位置を保ったまま向きを変える |

- 位置の欄は、入力していない間は有効数字 3 桁の科学表記で出ます。欄を選ぶと、全桁の値が出ます。
- 1 つの軸を書き換えたとき、ほかの 2 軸は全桁の値のまま使います。表示の丸めで視点が動くことはありません。
- 角度の欄は yaw・pitch・roll の操作ではありません。
- 欄を編集している間は、視点が動いても欄の値を書き換えません。

欄の上には、必要なときだけ次の行が出ます。

| 行 | 内容 |
| --- | --- |
| ⚠ 位置を移動できませんでした（有限のLogical十進数または科学表記を入力してください）。 | 位置の欄の値を受け付けなかった。次に位置か角度を確定するか、欄を編集し始めると消える |
| ⚠ 向きを変更できませんでした（floatで表現できる有限の角度を入力してください）。 | 角度の欄の値を受け付けなかった |
| ⚠ 高精度ビューポートが無効です（{0}）。実座標圏（視点）の外は正しく描けません。 | Radial の表示で、高精度の描画を止めている対象がある。{0} に理由が出る |
| ⚠ この位置はfloatで表現できません（実座標圏（視点）の外）。対数(Radial) Scene Viewでのみ正しく表示されます。 | 視点が `float` で表せない位置にある。位置は制限しない |
| Nav の行 | 下の表を参照 |

Nav の行には、ホイールで近づく基準までの距離と、右ドラッグ + W/A/S/D/Q/E で飛ぶ速さが出ます。

| 表示 | 出るとき |
| --- | --- |
| Nav: {1} 表面まで {0} ｜ 飛行速度 {2} | 選択した対象の表面までの距離を求められる |
| Nav: pivotまで {0} ｜ 飛行速度 {1} | 選択が無い、または表面までの距離を求められない |
| Nav: 利用不可 ｜ 飛行速度 {0} | Pivot までの距離を求められない |
| Navigator: orthographic ready | 平行投影の Scene View |

操作の途中は、Nav の行が操作の状態の表示に変わることがあります。

## 操作・表示設定

折り畳みの項目です。中身は上から次の順に並びます。

### 描画経路、実座標圏（物体）

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 描画経路 | `Auto` は、全体の AABB が実座標圏（物体）の中にある対象だけ、元の Renderer で描く。`Force Proxy` は、その中にある対象にも有限な描画用の Proxy を使う | `Auto` |
| 実座標圏（物体） | Mesh のアセットの Bounds を含む、全体の AABB に使う ± のしきい値（m）。履歴による余裕（ヒステリシス）は無い。視点の側の実座標圏（視点）とは別の値 | 10000 m |

この 2 つは、すべての Scene View で共通の値です。Editor を閉じるまで保持します。

### 安全境界

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 安全境界面を表示 | Scene View の有限な安全境界の、X / Y / Z の半透明の面を出す。境界線はオフのときも出る。通常の編集ではオフのままにする | オフ |

### グリッド

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| グリッドをカメラ追従 | オフでは、3 つの面を原点（X=0、Y=0、Z=0）に置く。オンでは、カメラの位置のグリッドの刻みへ合わせて追従させる。原点から遠くてもグリッドが画面に残る | オフ |
| グリッド基準 (10^n m) | 1 マスの基準の大きさを 10 の n 乗 m で指定する。下限の指定で、画面での見かけの間隔に応じて 10 倍ずつ間引く。範囲は −4 から、Logical の数値で表せる上限まで | 0（1 m） |
| X の行 | チェックで X が一定の面（YZ 面）を描く。色の欄で色と不透明度（アルファ）を決める | オン、赤系 |
| Y の行 | チェックで Y が一定の面（XZ 面）を描く。色の欄は同上 | オン、緑系 |
| Z の行 | チェックで Z が一定の面（XY 面）を描く。色の欄は同上 | オン、青系 |
| グリッドを既定へ戻す | 「グリッドをカメラ追従」、面の表示、色を既定へ戻す。グリッド基準は変えない | — |

グリッドの設定は、標準の表示と Radial の表示で共通です。

### 独自ナビゲーション

飛ぶ速さとホイールでの接近の設定です。値はプロジェクトの設定（`ProjectSettings/OmniEditorSettings.asset`）に保存します。

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 自動速度の秒数 | 選択した対象の表面（選択が無いときは Pivot）までの距離を、およそこの秒数で進む速さを、飛ぶ速さの基準にする | 2.5 秒 |
| 予備速度 | 基準の速さを自動で決められないとき（対象の内側にいるときなど）だけ使う速さ（m/s） | 10 m/s |
| 飛行速度の段比率 | 右ボタン + ホイールの 1 段あたりの倍率。段の数に上限は無い | 2 |
| 接近の縮小率 | ホイール 1 段で残りの距離を詰める割合。5%詰める（既定）、10%詰める、20%詰める、30%詰める、50%詰める、70%詰める から選ぶ | 5%詰める |
| 接近の最小距離 | ホイールで近づくときの、表面までの残りの距離の下限（m） | 0.000001 m |
| ホイール感度 | ホイールの量がこの値を超えるごとに 1 段進む | 1 |
| 1回で進む段数の上限 | 速くホイールを回したときに、1 回のイベントで進む段数の上限 | 8 |
| 見回しを左右反転 | 右ドラッグの見回しの左右を反転する | オフ |
| 見回しを上下反転 | 右ドラッグの見回しの上下を反転する | オフ |

### 視点編集

注視点と距離を保ったまま視点を動かす補助のボタンです。

| 項目 | 内容 |
| --- | --- |
| 編集尺度 | 最後に F でフォーカスした対象の大きさ |
| 左15°、右15°、上15°、下15° | 注視点と距離を保って、視点を 15° 回す |
| 1段近づく、1段離れる | 注視点までの距離を 5/6 倍、6/5 倍にする。平行投影では表示の範囲を 1/1.2 倍、1.2 倍にする |
| フォーカス前の視点へ戻る | F でフォーカスする前の視点へ戻す。履歴は 16 件まで持ち、押すごとに 1 件ずつ戻る |

- これらのボタンは、視点が「主観」の Radial の表示のときだけ使えます。
- 15° 回すボタンは、2D モードのとき、回転をロックしているときは使えません。
- 「フォーカス前の視点へ戻る」は、履歴が無いときは使えません。
- 同じ操作は Shortcut Manager の `Omni/Editing/*` にもあります。初期のキーは割り当てていません。[ショートカットとメニュー](../shortcuts-and-menus/) を読んでください。
- この節の見出し以外の文字（ボタン、編集尺度、案内）は、Editor の言語の設定にかかわらず日本語で出ます。

## デバッグ

表示が欠けたときなどに使う、診断用の折り畳みの項目です。通常の編集では閉じたままにします。

| 項目 | 内容 |
| --- | --- |
| カリングの使用 | オフにすると、Omni によるカリングと非表示をすべて止めて（fail-open）、消えた物の原因を調べられる。有限な描画用の Proxy は描画の安全のための仕組みなので止めない。既定はオン。すべての Scene View で共通で、Editor を閉じるまで保持する |
| カリングは無効です — … | 「カリングの使用」がオフのときだけ出る警告 |
| 選択対象 | 選択した GameObject の Renderer の、描画の経路、理由、非表示にした層、錐台の判定、実距離と描画深度、カリング Bounds の状態 |
| Bounds上書き: {0}  未対応: {1} | カリング Bounds を上書きした Renderer の数と、未対応として外した数 |
| カリング範囲 | 直前のフレームで使ったカリングの範囲（描画の near / far と、それに当たる実距離） |
| Logical Near Clip | 直前のフレームで使った Logical の Near Clip と、描画の near |
| ワープ経路 | 直前のフレームの写像の経路。対数（Radial）か、恒等（ワープなし）とその原因 |
| 目の上書き | 直前のフレームで、目の位置をワープの中心へ上書きしたか |
| Trackball Orbit | 直前の Alt + 左ドラッグの Orbit の入力と、固定した Logical の Pivot |
| 不変条件 | 監視している不変条件ごとの結果。破れは最初に起きたときの状態を保持する |
| 不変条件の記録をクリア | 保持した破れの記録と、初回のログの抑制を消す |
| 直近フレームの非表示 | 直前のフレームで、層ごとに非表示にした数 |
| 未対応Renderer／Material | 未対応として外した Renderer と Material の一覧 |
| マテリアルは自動生成されません。… | Material は Omni Manager の Materials / Shaders のタブで作る、という案内 |

デバッグの中身は、折り畳みを開いている間だけ更新します。
